# DefinitelyNotA_TeamsPresenceBot.ps1

A highly advanced productivity enhancement tool that performs absolutely critical workplace activities such as moving the mouse, clicking random places, checking Teams, and then returning to "work."

Built for educational purposes, office humor, and questionable levels of automation.

## Features

- Moves the mouse around to simulate intense computer activity
- Performs random desktop clicks
- Switches to Microsoft Teams
- Waits patiently between operations like a true enterprise application
- Repeats every 15 minutes

Run with PowerShell:

```powershell
.\DefinitelyNotA_TeamsPresenceBot.ps1
